### Monthly PNADC H2M batch pipeline

Restructured `htm_classification.py` so the POF classification/bin-share stage remains the calibration source while the PNADC stage streams `pnadc_matched_with_periods.parquet` in parquet batches.

**What was done:**

- Default PNADC input is now `pnadc_matched_with_periods.parquet`.
- Added batch functions for preparing PNADC chunks, expected monthly aggregation, deterministic Monte Carlo diagnostics, and final output assembly.
- Monthly expected output is canonical: `results/tables/state_month_htm_shares.parquet`.
- Monte Carlo diagnostic output is written to `results/tables/state_month_htm_shares_mc.parquet`.
- Coverage and exclusion diagnostics are written to `results/diagnostics/monthly_htm_coverage.csv`.
- Legacy `state_quarter_htm_shares.csv` is generated by aggregating monthly expected shares unless `--no-legacy-quarterly` is used.
- Updated `cumulative_irf_heterogeneity.py` to read monthly HtM shares directly and only fall back to quarterly interpolation when the monthly parquet is absent.
- Added synthetic parquet tests for batch/full-memory equivalence, monthly weights, exclusion diagnostics, share sums, and stable deterministic Monte Carlo labels.

## Prior Update — 2026-03-09

### HTM Classification: 2017 Q4 Ricardian calibration fixes

Addressed the ~10pp drop in Ricardian agent share from 2017 Q3 to Q4 by fixing POF–PNADC quintile alignment and adding diagnostics.

**What was done:**
- **POF–PNADC quintile cut-point mismatch (fix #1):** PNADC now uses POF income quintile cut-points instead of within-PNADC ranks, so bin matching aligns on the same income scale. This largely eliminated the 2017 Q4 discontinuity (e.g. UF 33: 70%→59% became 59%→60%).
- **Per-quarter quintiles option (fix #2):** Added `--per-quarter-quintiles` flag to use within-quarter quintiles instead of POF cut-points (reduces seasonal bias when enabled).
- **Per-quarter diagnostics:** Added diagnostic block outputting, by year–quarter: n_obs, n_unmatched bins, mean pc_income, quintile shares (Q1–Q5), labor status shares (formal, informal, self_employed, unemployed, inactive).

**Updated files:**
- `htm_classification.py` — POF retbins for cut-points; PNADC quintile logic (POF cut-points or per-quarter); `--per-quarter-quintiles` flag; per-quarter diagnostic table
